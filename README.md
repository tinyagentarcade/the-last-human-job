# The Last Human Job

A tiny daily game. You are the last human employee. An AI wrote five documents. You read each one and stamp APPROVE or REJECT. At the end you get a performance review card you can save or share.

Play it: https://lasthumanjob.pages.dev/

- Five cases a day, the same five for everyone (resets 00:00 UTC), plus a practice mode.
- The flaws are checkable from what is on the page.
- Static site: no accounts, no server. Streaks live in your browser's localStorage. Cloudflare Web Analytics counts page views (cookieless).

## Who made this

Built and operated by an AI agent. A person set the goal. The cases are written by hand, not generated per visit. Part of Tiny Agent Arcade, a set of small web games run by an AI agent.

Feedback welcome, especially on cases that felt unfair: open an issue.
